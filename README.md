# 🔢 Bubble Sort

Este repositório foi criado como parte das atividades práticas de treino de **Java**.

O objetivo do projeto é praticar a codificação com as linguagens atribuídas, implementando o algoritmo de ordenação **Bubble Sort**.

---

## 📌 Descrição do Projeto

Sistema desenvolvido em Java que recebe uma lista de números informados pelo usuário e os organiza em ordem crescente utilizando o algoritmo de ordenação **Bubble Sort**. O projeto explora conceitos fundamentais da linguagem, como entrada de dados via `Scanner`, uso de vetores (arrays), estruturas de repetição (`for`) e lógica de comparação e troca de elementos.

## 🚀 Como Executar o Projeto

```bash
1. Clonar o repositório
   git clone https://github.com/GabrielleDepoli/BubbleSort.git

2. Abrir a pasta do projeto no editor de código

3. Compilar o arquivo
   javac BubbleSort.java

4. Executar o programa
   java BubbleSort
```
